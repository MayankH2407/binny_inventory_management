Setup Guide

TSC Printer Setup
for Binny Inventory

Configure 100mm × 50mm media on Windows for two-up child-box label printing

Audience End user / on-site IT support at Binny Footwear
Goal Print two 50×50mm stickers per row on a 100mm-wide roll, both QR codes scannable
Time required ~10 minutes (one-time setup)
Last updated 4 May 2026

i Prerequisites

  • Windows 10 or 11 PC, with administrator rights on the local machine.
  • TSC label printer connected directly via USB.
  • 100mm-wide thermal label roll loaded with two 50×50mm die-cut labels per row (small gap between labels and between rows).
  • Latest Chrome or Edge browser.
  • TSC Seagull-based driver installed — not a generic Microsoft text driver. See the note in Step 1 if in doubt.

? Why this guide exists

Earlier the system printed one 50×50mm label per page (1-up). On 1 May 2026 the print template was updated to 2-up mode (two 50×50mm labels per 100×50mm page) so the full width of the roll is used and no half-row is wasted.

For the new layout to print correctly, the printer driver's media size must match the new page size (100mm × 50mm). If the driver is still configured for the old 50×50mm media, Windows scales the 100×50mm content down to fit 50mm width — exactly 50% scale — and the result is the wrong size (approximately 50×25mm of squashed content per sticker).

CSS and browser settings cannot override the driver's media size. The driver must be reconfigured one time. After that, all subsequent prints work without manual adjustment.

What you'll do

  1. Open Printer Properties
  2. Define a 100×50mm custom stock
  3. Set the new stock as the default in Printing Preferences
  4. Set the new stock as the system-wide default (critical)
  5. Calibrate the gap sensor
  6. Print a test page from Chrome
  7. Expected result
  8. Troubleshooting

1 Open Printer Properties

  1. Press Win + R, type control printers, press Enter.
    Alternative: Settings → Bluetooth & devices → Printers & scanners → click the TSC printer → "Printer properties".
  2. In the printer list, right-click the TSC printer → Printer properties.
  3. Confirm you see tabs that include Stocks and Tools in addition to the standard Windows tabs (General, Sharing, Ports, Advanced, Color Management, Security).
i
"Printer properties" — not "Printing preferences" yet The Windows dialog with multiple tabs (General, Sharing, Ports, Advanced, Stocks, Tools, …) is what you want. We'll get to Preferences inside this dialog later.
!
If "Stocks" / "Tools" tabs are missing The wrong driver is installed (likely a generic Microsoft text driver, not the TSC Seagull driver). Download and install the correct TSC Windows driver for your model from tscprinters.com → Support → Drivers → search by model. Then return to Step 1.

2 Define a 100×50mm custom stock

  1. Click the Stocks tab.
  2. Click New…
  3. Fill in the dialog as shown below:
FieldValue
NameBinny 100x50 2up
DescriptionTwo 50x50mm labels per row (optional)
Stock TypeLabels with Gaps  ← must be this
Width100.0 mm
Height (or "Length")50.0 mm
Liner Width100.0 mm (same as Width unless your liner is wider)
Gap (between labels)3.0 mm (see note below)
Sensor TypeGap (transmissive — the default)
i
About the Gap value Measure the actual gap between two consecutive rows on the roll if you can (a vernier caliper or a printed ruler works). Common values are 2.0, 2.5, or 3.0 mm. If unsure, start with 3.0 mm — if Step 5 calibration fails or the printer skips rows, come back here and reduce to 2.0 mm.
  1. Click OK to save the stock.

You should now see Binny 100x50 2up in the Stocks list.

3 Set the new stock as the default in Printing Preferences

  1. Switch back to the General tab in Printer properties.
  2. Click the Preferences… button.
  3. In the Preferences dialog, go to Page Setup tab.
  4. Under Stock, open the dropdown and select Binny 100x50 2up.
  5. (Optional) On the Options tab, set:
    • Speed: 4 IPS (safe default)
    • Darkness: 8–10 (thermal-direct rolls)
  6. Click Apply, then OK to close Preferences.

4 Set the new stock as the system-wide default

!
This step is the one most commonly missed Chrome reads the system default, not the per-user Preferences. If you skip this, Chrome will keep using the old 50×50mm media and the symptom returns even though Preferences look correct.
  1. Back in Printer properties, click the Advanced tab.
  2. Click Printing Defaults… (this is a separate button from "Preferences" on the General tab — both must be set).
  3. Repeat the same selection as Step 3:
    Page Setup → Stock → Binny 100x50 2up.
  4. Click Apply and OK.
  5. Click OK on Printer properties to close everything.

5 Calibrate the gap sensor (one-time)

The printer needs to relearn where the gaps between labels are.

Driver-side calibration (preferred)

  1. Open Printer properties again → Tools tab.
  2. Click Calibrate Sensor (or "Auto Calibrate").
  3. The printer feeds 2–3 labels and stores the new gap pattern.

Hardware-side calibration (if no Tools button is available)

  1. Power off the printer.
  2. Hold the FEED button while powering it on.
  3. Release the FEED button once the LED flashes amber, then green.
  4. The printer auto-feeds a few labels and calibrates.
✓
Quick test Press the FEED button once. The printer should advance exactly one row (50mm) and stop with the next blank label cleanly aligned at the tear bar. If it skips a row or stops mid-label, redo this step with the Gap value tweaked in Step 2.

6 Print a test page from Chrome

  1. Open Chrome and navigate to the Binny Inventory portal.
  2. Sign in. Go to Child Boxes → Generate Labels.
  3. Generate at least 4 labels (so we have two full rows for the test).
  4. On the success screen, click Print Labels. A new tab opens with the labels rendered.
  5. The browser print dialog appears. Configure as follows:
SettingValue
DestinationTSC printer
PagesAll
Paper sizeBinny 100x50 2up (or 100 x 50 mm)  ← must select
MarginsNone (or "Default" — minimum)
ScaleDefault or 100%  — NOT "Fit to printable area"
More settings → Background graphicsON
!
Critical: Paper size dropdown gotcha On the first print after driver changes, the "Paper size" dropdown sometimes still shows A4 or Letter even though the system default was set in Step 4. Select Binny 100x50 2up manually the first time. After that Chrome will remember it for this printer.
  1. Click Print.

✓ Expected result

  • Two adjacent 50×50mm labels print on the first row of the roll.
  • Each label fully filled: outer border, "Article No", colour, size, MRP, QR code, "Packed on", content quantity, and the manufacturer footer.
  • The printer advances 50mm to the next row.
  • The next pair of labels prints on row 2. And so on, two labels per row, one row per page.
  • Each QR code, peeled and stuck on a separate child box, scans independently with the BPS250BC scanner gun (or any standard 2D scanner).

! Troubleshooting

Symptom Most likely cause Fix
Still printing at ~50×25mm Step 4 (Printing Defaults) was skipped, or Chrome's "Paper size" still says A4 Redo Step 4, then re-check Chrome dialog Paper size in Step 6
Two labels print but printer advances 100mm (skips a row) Gap calibration is reading both label gaps as one big gap Reduce Gap value to 2.0mm in Step 2, redo Step 5
Labels drift downward over time Gap sensor not calibrated, or roll loaded slightly off-axis Re-run Step 5; reload the roll squarely against the guides
Right label is blank, left label is correct Driver still on 50×50mm media, OR Liner Width set to 50mm Re-check Step 2: both Width and Liner Width must be 100.0mm
Border or QR cut off near label edges Print offset shifted in driver Tools tab → set Horizontal/Vertical offsets to 0; recalibrate
QR code is fuzzy / fails to scan Darkness too low, or speed too high Preferences → Options → set Darkness to 10, Speed to 2 IPS
Chrome print dialog never shows the new stock size Printing Defaults (Step 4) wasn't saved, or Chrome cached the old printer profile Redo Step 4, restart Chrome, retry
Printer feeds blank labels but doesn't print anything Wrong stock type (e.g. "Continuous" instead of "Labels with Gaps") Step 2: ensure Stock Type = Labels with Gaps
Printer beeps and stops with red light Out of media, door open, or sensor blocked Reload roll, close door cleanly, clean the gap sensor with compressed air

? What if it still doesn't work after all steps

Send us the following so we can diagnose further:

  1. Exact TSC model number — printed on the label on the bottom or back of the printer (e.g. TE244, TDP-225, TTP-244 Pro).
  2. Screenshot of the Stocks tab showing the Binny 100x50 2up entry.
  3. Screenshot of Chrome's print dialog with all settings expanded (especially Paper size, Margins, Scale).
  4. Photo of the printed output with a ruler alongside one label.
  5. Photo of the roll showing the gap between labels (so we can confirm the Gap measurement).

With those five items we can pinpoint whether the issue is driver-side, browser-side, or media-side.
